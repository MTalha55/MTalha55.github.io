CSS3 Kapsamlı Ders Notları

Web sayfalarını şekillendirmek için kullanılan CSS kodları, seçiciler, Flexbox, Grid ve daha fazlası.

1. CSS Seçiciler (Selectors) - HTML'i Yakalamak

HTML dersimizde gördüğümüz <div>, class ve id yapılarını hatırlayın. CSS'te bir HTML elemanını renklendirmek veya şekillendirmek için önce onu seçmemiz (yakalamamız) gerekir. İşte seçiciler tam olarak bunu yapar.

  • Etiket Seçici: HTML etiketinin adını direkt yazarak seçeriz (Örn: p, div). Sayfadaki TÜM o etiketleri etkiler.
  • Class Seçici (.): Nokta işareti ile başlar. HTML'de class="kutu" dediğimiz elemanı CSS'te .kutu olarak seçeriz. Aynı stile sahip birden fazla elemanı şekillendirmek için harikadır.
  • ID Seçici (#): Diyez (kare) işareti ile başlar. HTML'de id="baslik" dediğimiz elemanı #baslik olarak seçeriz. Sayfada sadece o özel, tek elemanı etkiler.

2. Kutu Modeli (Box Model)

Her HTML elemanı bir kutu olarak düşünülür. İçten dışa: İçerik, Padding, Border, Margin.

.kutu { width: 300px; height: 200px; padding: 20px; /* İç boşluk */ border: 2px solid black; /* Çerçeve */ margin: 15px; /* Dış boşluk */ box-sizing: border-box; /* Genişliğe padding ve border'ı dahil et */ }

3. Renkler ve Arka Plan (Colors & Backgrounds)

.arkaplan-ornek { /* Renk Tanımlamaları */ color: #ff0000; /* HEX */ color: rgb(255, 0, 0); /* RGB */ color: rgba(255, 0, 0, 0.5); /* RGBA (Saydamlık) */ /* Arka Plan */ background-color: #f4f4f4; background-image: url('desen.png'); background-size: cover; /* Resmi sığdır */ background-position: center; /* Ortala */ /* Gradient (Geçişli Renk) */ background: linear-gradient(to right, red, blue); }

4. Metin Biçimlendirme (Text Formatting)

.metin-stili { font-family: 'Inter', sans-serif; /* Yazı Tipi */ font-size: 16px; /* Boyut */ font-weight: bold; /* Kalınlık (normal, bold, 400, 700 vb.) */ text-align: center; /* Hizalama (left, right, center, justify) */ text-decoration: none; /* Alt çizgi vb. (underline, line-through) */ text-transform: uppercase; /* Hepsini büyük harf yap */ line-height: 1.5; /* Satır yüksekliği */ letter-spacing: 1px; /* Harf arası boşluk */ }

Bu metin tam olarak yukarıdaki CSS kodları ile biçimlendirilmiştir. Ortalı, kalın, büyük harf ve harf arası boşluklu.

5. Flexbox (Esnek Kutu Düzeni)

Elemanları tek bir yönde (yatay veya dikey) hizalamak için harika bir düzendir.

.flex-container { display: flex; /* Flexbox'ı aktifleştir */ flex-direction: row; /* Yan yana diz (row, column) */ justify-content: center; /* Yatayda ortala (flex-start, space-between vb.) */ align-items: center; /* Dikeyde ortala */ gap: 15px; /* Elemanlar arası boşluk */ flex-wrap: wrap; /* Sığmazsa alt satıra geç */ } .flex-item { flex: 1; /* Mevcut alanı eşit paylaş */ }

6. CSS Grid Düzeni

İki boyutlu (satır ve sütunlar) düzenlemeler için kullanılır.

.grid-container { display: grid; /* 3 eşit sütun oluştur */ grid-template-columns: repeat(3, 1fr); /* 2 satır oluştur, ilki 100px, ikincisi otomatik */ grid-template-rows: 100px auto; gap: 20px; /* Izgara boşluğu */ }

7. Geçişler ve Animasyonlar (Transitions & Animations)

/* Geçiş (Transition) - Hover olunca yavaşça değişir */ .buton { background-color: blue; transition: background-color 0.3s ease, transform 0.2s; } .buton:hover { background-color: red; transform: scale(1.1); /* %10 büyüt */ } /* Animasyon (Keyframes) */ @keyframes salla { 0% { transform: translateX(0); } 50% { transform: translateX(10px); } 100% { transform: translateX(0); } } .animasyonlu-kutu { animation: salla 1s infinite; }

8. Medya Sorguları (Responsive Design)

Ekran boyutlarına göre farklı stiller uygulamak için kullanılır.

/* Varsayılan stil (Mobil öncelikli - örneğin) */ .konteyner { width: 100%; } /* Ekran genişliği 768px veya daha büyükse bu kodlar çalışır (Tablet/Masaüstü) */ @media (min-width: 768px) { .konteyner { width: 50%; } }
